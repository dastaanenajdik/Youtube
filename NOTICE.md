## omavcher/YouTube-Clone (MIT)

Layout, route structure and feature inventory for this project were adapted from
[omavcher/YouTube-Clone](https://github.com/omavcher/YouTube-Clone) — the four static pages
(`index.html`, `shorts.html`, `history.html`, `your_channel.html`) and their Bootstrap-based
stylesheet. The markup, images and Font Awesome assets were **not** copied: this app is a Next.js /
TypeScript rebuild with its own hand-written CSS and `lucide-react` icons. The upstream MIT license
is reproduced below.
